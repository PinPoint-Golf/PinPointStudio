# Contributing

How work is done here is in [`governance/`](governance/README.md). Before your first change, read the working contract, [`governance/AGENTS.md`](governance/AGENTS.md): one page of non-negotiables and how an issue is worked, with an index of what to read for each kind of work. A change to an on-disk format, to which object owns what, or to the design system is agreed with the owner before it is built.
