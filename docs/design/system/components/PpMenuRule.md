# PpMenuRule

The hairline between groups of PpMenuItem lines in a popup menu — it sets the destructive line apart in its own group.

Source: `src/Gui/components/PpMenuRule.qml`.

## Usage
Place between PpMenuItems in the menu's Column. No props.

## Tokens & values
1 px `colorBorderMid` at `borderOpacityNormal` (0.5), the menu's width less 12 px, inset 6 px each side.
