# Cluster A (interactive primitives): re-check, 31 Oct 2026

**What was checked.** Each of the 19 findings in [A-interactive-primitives.md](A-interactive-primitives.md) (19 Oct, commit `8f5225a8`), re-counted at HEAD **`9ac19450`**. I also read the new shared components (`PpBandBar`, `PpCheckRow`, `PpDeviceFilterBar`, `PpDeviceTags`, `PpExpandRow`, `PpFilePicker`, `PpRowAction`, `PpTableRow`, `PpConfirm`) in full. The other files added since `8f5225a8` were scanned only for hand-rolled switches, buttons, chips, fields, links and pickers: `settings/StudioPanel.qml`, `report/*.qml`, `athlete/ScreenSessions.qml`, `home/Hm*.qml`, `setup/pages/{CalibrateTrunk,CheckTrunk,Intent}Page.qml`, `charts/PpChPosture*`, `charts/PpChDelivery*`.

**Method.** Read-only; nothing was built or run. All paths are relative to `src/Gui`, and every count leaves out `tests/`. For each count I ran the same grep or script on HEAD and on a `git archive 8f5225a8` copy of the baseline, so "then → now" uses one method on both sides. Where my baseline number differs from the 19 Oct report, the table says so. Line numbers were read from the HEAD files.
- **Switches:** files declaring `component TogglePill` / `component MiniToggle`, plus every Rectangle whose thumb uses `x: … ? parent.width - width - Theme.sp(3|2) : …`. Use sites come from `TogglePill {` / `MiniToggle {` / `SetupTogglePill {`.
- **Hand-rolled buttons and chips (A2):** a script that matches a `Rectangle` sized `<label>.implicitWidth + Theme.sp|gap(N)`, with a hover term (`hovered` / `containsMouse` / `HoverHandler`) and a press handler (`MouseArea` / `TapHandler` / `PpPressable`) within 40 lines. It misses blocks whose `Rectangle {` is more than 8 lines above the width line, so it counts low. The 19 Oct report's "≈87" used a looser method; on both trees this script finds 77.
- **Shared-component adoption:** `grep -E "(^|[^A-Za-z0-9_])PpX *\{"`, leaving out the component's own file.
- **Hand-rolled links:** a script that matches a `Text {` block with `color: … Theme.colorAccent` and a press handler inside, leaving out `PpLink.qml`.

- **Effort:** S (≈90 lines). Risk: the 20 px width difference.
- **Confidence:** high.
