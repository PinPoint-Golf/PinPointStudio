### B26. Byte-size formatting: `bytesWords` ×3 identical, plus five more formatters that disagree on what a GB is
- **Verdict:** TRUE DUPLICATE (3) + PARALLEL IMPLEMENTATION (5)
- **Where:** identical `bytesWords(b)`: `athlete/ScreenSessions.qml:57–62`, `report/PpSessionReportList.qml:399–404`, `report/PpSessionsSelectionBar.qml:53–58`. Other byte formatters: `report/PpSessionsTableRow.qml:114–118 sizeWords` (binary, MB/KB), `monitor/RmPpcpPhoneCard.qml:72–77 fmtStorage` (binary, GB/MB, MB to 0 dp), `settings/StoragePanel.qml:49–55 formatBytes` (**SI** 1e9, MB to 1 dp), `settings/ArchivingPanel.qml:81–87 formatBytes` (SI, MB to 0 dp), `components/PpFilePicker.qml:87–92 _formatSize` (SI, MB/KB/B). C++ already uses `QLocale().formattedDataSize` (`main.cpp:777`).
- **What is duplicated:** three copies of one 6-line function, and five more ways to do the same job. The Sessions screen divides by 1024³ and Settings → Storage/Archiving divide by 10⁹. A 14.6 GB library on the Sessions header therefore reads about 15.7 GB in Settings → Storage, and the empty value is "0 MB", "", or "—" depending on the file.
- **Proposed single home:** one `Theme.formatBytes(b, empty)` (next to `Theme.formatHandicap`), or a C++ invokable that wraps `QLocale::formattedDataSize`. Pick one base and one empty mark, then delete the eight local functions.
- **Effort / risk:** S. Visible: one screen's numbers change by about 7 %. Mark should choose binary or SI.
- **Confidence:** high

### B27. `plural(n, one, many)` ×3, and plurals that bypass Qt's `%n`
- **Verdict:** TRUE DUPLICATE
- **Where:** `athlete/ScreenSessions.qml:63 plural`, `report/PpSessionsSelectionBar.qml:59 plural`, `report/PpSessionReportList.qml:405 _plural`, all character-identical. The same choice is also written inline: `home/ScreenHome.qml:94,380`, `home/HmAreaRow.qml:80`, `shot/PpShotActionBar.qml:200,262`, `setup/SetupSteps.qml:93`, `setup/pages/ImusPage.qml:143`.
- **What is duplicated:** `n === 1 ? one.arg(n) : many.arg(n)`. It is English-only by construction: two `qsTr` strings chosen in QML. Qt's own form, `qsTr("%n session(s)", "", n)`, lets a translation supply its own plural forms.
- **Proposed single home:** `Theme.plural()` as a stop-gap. The real fix is `qsTr("%n …", "", n)` at each call site, which needs no helper at all.
- **Effort / risk:** S
- **Confidence:** high (the duplication); medium on whether to switch to `%n` now (there are no translations yet)
